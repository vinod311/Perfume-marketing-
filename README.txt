TRIVENKEM FRAGRANCE FINDER - GitHub only version (no login, no database)

PUT ON GITHUB
1. Upload ALL files in this folder to your repository (index.html must be in the main folder). Commit.
2. Settings > Pages > Deploy from branch > main > / (root) > Save.
3. Open https://YOURNAME.github.io/REPO/ on your phone, then Add to Home screen.

USING IT
- Works offline after the first open.
- Add / edit / star / delete is saved inside that phone's browser only.
- After every update take Import / Export > Backup (JSON). Keep the file safe.
- Another phone: open the link there and Import the backup file.
- Many fragrances at once: Import / Export > Blank template (CSV), fill in Excel, Import.
- To change the starting 42 fragrances for everyone: edit data.js on GitHub.
